# Brainery
Build a simple Task Manager web application using Django and Python. In this hands-on lab, you will create a Django project, define a Task model, connect it to a database, and build a basic page to display and add tasks. This lab introduces the core Django development flow from models and views to URLs, templates, and forms.


Coding Lab: Building a Simple Task Manager with Django
Lab Objective

In this lab, you will build a simple Task Manager web application using Django and Python.

You will work with the core Django development flow:

Model → Database → View → URL → Template → Form

By the end of the lab, you will have a working application that allows users to view and add tasks.

Scenario

A small development team needs a simple internal application to track their tasks.

Each task should contain:

Title – Name of the task
Description – Details about the task
Status – Current progress of the task
Created At – Date and time the task was created

The application should allow users to view existing tasks and add new ones.

Prerequisites

Before starting, make sure you have:

Python installed
Basic Python knowledge
Basic HTML knowledge
A code editor
Familiarity with running commands in a terminal
Part 1: Set Up the Django Environment
Create a new project directory.
Create and activate a Python virtual environment.
Install Django using pip.
Verify that Django is installed successfully.
Checkpoint

Confirm that Django is installed and the virtual environment is active before continuing.

Part 2: Create the Django Project

Create a Django project named:

taskmanager

Then:

Navigate into the project directory.
Start the Django development server.
Open the application in your browser.
Verify that the default Django page is displayed.
Checkpoint

The Django development server should start successfully and the application should be accessible from your browser.

Part 3: Create the Tasks App

Create a Django application named:

tasks

Then:

Add the tasks application to INSTALLED_APPS.
Review the files generated by Django.
Confirm that the application is connected to the project.
Part 4: Create the Task Model

Create a Task model inside the tasks application.

The model should contain:

Field	Purpose
title	Stores the task name
description	Stores task details
status	Stores the current task status
created_at	Stores when the task was created

The status field should support:

Pending
In Progress
Completed

Create and apply the required database migrations.

Checkpoint

Verify that the migrations complete successfully and the Task model is available in the database.

Part 5: Configure Django Admin

Register the Task model with Django Admin.

Then:

Create a Django superuser.
Start the development server.
Open Django Admin.
Log in using the superuser account.
Create at least three sample tasks.
Checkpoint

You should be able to create and manage Task records through Django Admin.

Part 6: Display Tasks

Create a Django view that retrieves all tasks from the database.

Then configure a URL:

/tasks/

The URL should connect to your task-list view.

Create a template that displays:

Task title
Description
Status
Created date

Use Django template syntax to dynamically display the tasks.

Checkpoint

When you visit /tasks/, the tasks created through Django Admin should be displayed on the page.

Part 7: Add New Tasks

Extend the application so that users can create new tasks from the application.

Your implementation should:

Provide a form for entering task information.
Accept the submitted data.
Validate the input.
Save the task to the database.
Redirect the user back to the task list after successful creation.
Checkpoint

Create a new task through the application and confirm that it appears in the task list.

Final Validation

Before completing the lab, verify that your application can:

Start successfully using the Django development server

Store tasks in the database

Manage tasks through Django Admin

Display tasks at /tasks/

Add new tasks through the application

Display task status and creation date

Successfully save newly created tasks to the database

Expected Outcome

You should finish the lab with a functional Django Task Manager application demonstrating the basic Django workflow:

Models → Migrations → Views → URLs → Templates → Forms → Database
